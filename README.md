# 320 N. Lincoln

A browser party game set at a house party at 320 N. Lincoln in Bloomington, Indiana. Pimmel has to keep the party alive from pregame until the Kirkwood bars let out, flicking drinks to Zan, Arshan, Rick, Fowler, Mark, Greg and a very mad Mitchell.

**Play:** https://kpoconno.github.io/320Nlincoln/

- Pick a drink from the cooler, swipe up to throw. Longer swipe, farther throw.
- Land it in the ring. Dead center is a perfect toss.
- Misses waste cans. Storm-offs drain the vibe. Vibe hits zero and you get dropped.

Single self-contained `index.html`, works on phones. Add it to your home screen for full screen.
